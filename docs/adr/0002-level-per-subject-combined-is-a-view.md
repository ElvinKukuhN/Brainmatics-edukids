# A Level belongs to one Subject; "combined" is only a view

The Software Request asks for levelling to be tracked "separately or combined" (*terpisah maupun gabungan*). We model one Level per Student per Subject, promoted independently, and there is no overall Level. "Combined" means only the Combined View: the Report Card and dashboard show all of a Student's Subjects side by side. Calculating an overall Level would need a formula across Subjects that have different Level counts, and nobody at the centre makes decisions from such a number.
